# Тестовое задание: Инженер по интеграции

Этот репозиторий содержит решения тестовых заданий.

## Структура
- 02-warehouse/ — задача по складской логике (FBS, маркировка, инвентаризация).
- 04-incidents/ — задача по разбору инцидентов по логам.

## Как запустить задачу 02 (Склад)
Убедитесь, что у вас установлен PHP 8.1 или выше.
cd 02-warehouse
php run.php

## Принятые решения
1. Приоритезация: задания сортируются по ship_by (ASC). Более срочные забирают остатки первыми.
2. Маршрутизация: лист подбора сортируется по адресу ячейки для минимизации пути кладовщика.
3. Валидация КИЗ: проверка формата и глобальная проверка на дубликаты.
4. Инвентаризация: учитываются уже собранные товары.
